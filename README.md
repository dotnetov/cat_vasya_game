# cat_vasya_game

## Модуль 1. Абстрактный класс Unit, персонаж и монстр

В первом модуле был создан абстрактный класс `Unit`.

Класс `Unit` содержит шесть основных характеристик юнита:

- сила;
- ловкость;
- телосложение;
- мудрость;
- интеллект;
- харизма.

Также в классе объявлены абстрактные методы:

- `calculate_max_health()` – расчёт максимального здоровья;
- `calculate_damage()` – расчёт урона;
- `calculate_defense()` – расчёт защиты.

От класса `Unit` могут наследоваться конкретные игровые сущности, например:

- `Character`;
- `Monster`.

Абстрактный класс `Unit` нельзя использовать для создания объекта напрямую.
Он нужен для задания общей структуры всех игровых юнитов.

## Модуль 2. Игровые классы внутри Character

Во втором модуле была изменена архитектура проекта.

Вместо создания отдельных классов для воина, мага и охотника используется один
класс `Character`.

Поведение персонажа зависит от значения атрибута `character_class`.

Доступные классы персонажа:

- `warrior` – воин;
- `mage` – маг;
- `hunter` – охотник.

Для каждого класса персонажа используются собственные формулы расчёта:

- урона;
- защиты;
- максимального здоровья.

При создании объекта персонажа сразу рассчитываются основные параметры:

- максимальное здоровье;
- текущее здоровье;
- урон;
- защита.

Также реализована проверка корректности выбранного класса персонажа.
Если передан неизвестный класс, программа вызывает исключение.

## Модуль 3. Заклинания и мана

В третьем модуле была добавлена система магии.

Создан абстрактный класс `Spell`, который хранит:

- название заклинания;
- урон;
- стоимость в мане.

В классе `Spell` объявлен абстрактный метод `cast()`.

Также были реализованы конкретные заклинания:

- `Fireball` – огненный шар;
- `IceLance` – ледяное копьё;
- `LightningBolt` – молния.

В класс `Unit` были добавлены:

- список заклинаний `spells`;
- текущая мана `mana`;
- метод `add_spell()` для добавления заклинаний;
- метод `cast_spell()` для использования заклинаний.

При использовании заклинания проверяется количество маны.

Если маны достаточно:

1. стоимость заклинания вычитается из текущей маны;
2. вызывается метод `cast()`;
3. возвращается урон заклинания.

Если маны недостаточно, программа вызывает ошибку.
